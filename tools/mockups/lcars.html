LCARS

Six takes on a DS9/Voyager-era OSD for Four Dash Two — the condensed Starfleet type, segmented color rails, the elbow sweep — plus one Original Series throwback. Same telemetry every time, arranged minimally the LCARS way. Pick a direction and I'll bake the font and palette into the goggle font.

These are mockups of the look, not the live OSD yet. The goggle draws from a fixed character grid, so the real build approximates LCARS with block glyphs for the rails and a condensed font baked into the goggle font (same gold/red palette system as now). The sweeping curves are a target — on the grid they'll read as stepped blocks. Tell me the number and I'll build the font + a matching CLI colour map.
